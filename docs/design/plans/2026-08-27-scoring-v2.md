# Scoring v2 Implementation Plan

**Goal:** Score every relay attempt against the endpoint that produced it, collapse a batch to one signal per endpoint, add a chronic-failure rate term to the reputation score, make latency reporting-only, and make PATH's scoring config keys live.

**Architecture:** A new `score` middleware sits inside retry/hedge/batch just outside `heuristic`, and records one `reputation.Signal` per attempt (or adds it to a batch-wide `ScoreSink` that batch flushes worst-of). The reputation service keeps per-key `State{Score, Rate, Attempts, TrafficAttempts, LatencyMS}`; the additive `Score` is today's term, `Rate` is an EWMA of failure weight per attempt, and every reader sees `effective = clamp(Score + Penalty(Rate))`. Observe stops scoring when the `scoring_v2` flag is on.

**Tech Stack:** Go (version per `go.mod`), testify, Prometheus client, go-redis. Standard gates: `go build ./... && go vet ./... && gofmt -l .`, `make test_unit`, `make go_lint`, `make docs`.

**Spec:** `docs/design/specs/2026-08-27-scoring-v2-design.md`, arguing from `docs/scoring.md` §3–§7.

## Global Constraints

- One attempt is one scoring event; attribution follows the response (`docs/scoring.md` §3.1–3.2).
- Client-attributed outcomes (`heuristic.AttrClient` with an error) are nobody's signal: never recorded, never an attempt.
- Never a bare `go` statement — `internal/safego` (`CLAUDE.md`).
- Config: value types only; zero = default; negative = off where "off" exists; every new config field has a doc comment; `make docs` must be clean afterwards.
- A config key SAGE parses but does not act on must be in `config/inert.go`'s registry AND its doc comment must say "parsed and not implemented" (`TestInertRegistryCoversDocComments`).
- Feature flag defined once in `featureflag.DefaultFlags` via a `Flag*` constant; referenced only by the constant.
- Every test must fail against a revert of the change it covers and must assert the *right* signal, not a count.
- `relay.Context.Clone()` is shallow: any new pointer field is shared across the request tree — say so in its doc comment.
- Exported symbols and packages need doc comments starting with their own name (`revive`).
- Signal type strings that survive (`success`, `minor_error`, `major_error`, `critical_error`, `fatal_error`) keep their exact values — timelines and the `signal_impacts` YAML keys depend on them.
- Rate-term defaults, verbatim: half-life 20000 attempts, onset 0.0002, full 0.01, penalty −40 at full, −70 cap; failure weight critical/fatal 1, major 0.5, else 0.

## Rulings made while planning (deviations from the spec text)

1. **No separate `Outcome` type.** `reputation.Signal` (with a new `Probe bool`) *is* the per-attempt outcome; `RecordSignal` stays the one recording API. The spec's `RecordAttempt(Outcome)` would duplicate `Signal` field for field.
2. **`score` does not clear `ctx.HeuristicResult`.** `circuit_break` and `method_blocks` wrap `select_endpoint` from *outside* `score` and read the verdict after it returns. Attempt isolation is already guaranteed by Retry's per-attempt reset, Batch's per-sub-relay reset, and Hedge cloning a parent that has no verdict. The composition test proves it.
3. **No `ctx.scoringV2` field.** Observe, `score` and `batch` each read the flag per request. A flag flip mid-request can double- or zero-count that one request; that is an admin action, not a traffic pattern, and it is documented on the flag constant.
4. **Batch gets the flag store and the reputation service.** `Batch(maxConcurrentRelays, maxPayloads, flags, repSvc)` — it owns the sink, so it must own the flush.
5. **Selector thresholds are global.** One `TieredSelector` serves every service; `tiered_selection` and `min_threshold` are honoured from `gateway_config.reputation_config` only. Per-service copies of those keys are documented as global in the doc comment (the inert registry cannot express "live at one path, inert at another").
6. **Attempt counter via a service hook.** `sage_reputation_attempts_total` increments inside `reputation.Service.RecordSignal` through `SetSignalHook`, so traffic and probes are counted in one place.

// reputation/rate.go
package reputation

import "math"

// Defaults for the chronic-failure rate term. The numbers were chosen against
// PATH's mainnet defect rates (spacebelt 0.216%, rpcgate 0.065%, nodefleet
// 0.00003%) and a simulation of bursts on clean keys; docs/scoring.md §7.3
// has the table.
const (
	// DefaultHalfLifeAttempts is the EWMA half-life of the failure rate, in
	// attempts. Long on purpose: a 6-critical burst on a clean key must stay
	// under the onset, and only chronic behaviour should reach the penalty.
	DefaultHalfLifeAttempts = 20000
	// DefaultOnsetRate is the failure rate below which the term is zero.
	DefaultOnsetRate = 0.0002
	// DefaultFullRate is the failure rate at which the penalty is -40 points —
	// out of tier 1 and most of the way through tier 2.
	DefaultFullRate = 0.01

	penaltyAtFull = -40.0
	penaltyCap    = -70.0
)

// RateConfig parameterises the chronic-failure rate term of a reputation
// score. Zero values mean the defaults above; a negative HalfLifeAttempts
// turns the term off.
type RateConfig struct {
	// HalfLifeAttempts is the EWMA half-life in attempts. 0 = default,
	// negative = term off.
	HalfLifeAttempts int
	// OnsetRate is the failure rate at which the penalty starts. 0 = default.
	OnsetRate float64
	// FullRate is the failure rate at which the penalty reaches -40. 0 = default.
	FullRate float64
}

// Normalized returns the config with defaults filled in. Every method below
// assumes it has been called; NewService calls it once.
func (c RateConfig) Normalized() RateConfig {
	if c.HalfLifeAttempts == 0 {
		c.HalfLifeAttempts = DefaultHalfLifeAttempts
	}
	if c.OnsetRate == 0 {
		c.OnsetRate = DefaultOnsetRate
	}
	if c.FullRate == 0 {
		c.FullRate = DefaultFullRate
	}
	return c
}

// Enabled reports whether the term is on. Negative half-life is the off switch.
func (c RateConfig) Enabled() bool { return c.HalfLifeAttempts > 0 }

// Lambda is the EWMA step: rate += Lambda * (weight - rate).
func (c RateConfig) Lambda() float64 {
	if !c.Enabled() {
		return 0
	}
	return math.Ln2 / float64(c.HalfLifeAttempts)
}

// Penalty maps a failure rate to the points subtracted from the additive
// score: 0 up to OnsetRate, logarithmic to -40 at FullRate, continuing at the
// same slope to -70 (one decade past FullRate) and capped there.
func (c RateConfig) Penalty(rate float64) float64 {
	if !c.Enabled() || rate <= c.OnsetRate {
		return 0
	}
	span := math.Log10(c.FullRate / c.OnsetRate)
	if rate <= c.FullRate {
		return penaltyAtFull * math.Log10(rate/c.OnsetRate) / span
	}
	p := penaltyAtFull + (penaltyCap-penaltyAtFull)*math.Log10(rate/c.FullRate)
	if p < penaltyCap {
		return penaltyCap
	}
	return p
}

// FailureWeight is what one signal contributes to the failure rate: a
// critical or fatal error counts fully, a major error (a timeout, a 5xx)
// half, everything else zero. Client-attributed outcomes never reach the
// service and so are not attempts at all.
func FailureWeight(t SignalType) float64 {
	switch t {
	case SignalCriticalError, SignalFatalError:
		return 1
	case SignalMajorError:
		return 0.5
	default:
		return 0
	}
}

// reputation/state.go
package reputation

import (
	"context"

	"github.com/pokt-network/sage/domain"
)

// State is everything the service remembers about one reputation key.
//
// Score is the additive term (today's score). Rate is the EWMA failure rate
// the chronic term reads. Attempts and TrafficAttempts are counts for the
// admin listing — the second excludes health-check probes so "has anything
// real graded this key?" is answerable. LatencyMS is a traffic-only EWMA kept
// for reporting; it has no effect on any score and is not persisted.
type State struct {
	Score           float64 `json:"score"`
	Rate            float64 `json:"rate,omitempty"`
	Attempts        uint64  `json:"attempts,omitempty"`
	TrafficAttempts uint64  `json:"traffic_attempts,omitempty"`
	LatencyMS       float64 `json:"-"`
}

// StateView is State as the admin API presents it, with the derived values
// every reader actually keys on.
type StateView struct {
	Score           float64 `json:"score"`
	Additive        float64 `json:"additive"`
	Rate            float64 `json:"rate"`
	Penalty         float64 `json:"penalty"`
	Attempts        uint64  `json:"attempts"`
	TrafficAttempts uint64  `json:"traffic_attempts"`
	ProbeOnly       bool    `json:"probe_only"`
	LatencyMS       float64 `json:"latency_ms"`
}

// StateLister is the optional read interface the admin API asks a
// reputation.Service for. Keys are reputation keys at the configured
// granularity, as with GetScores.
type StateLister interface {
	GetStates(ctx context.Context, serviceID domain.ServiceID) (map[string]StateView, error)
}

// encodeState is the hash field value: JSON, so a field can grow without a
// key-format migration.
func encodeState(st State) string {
	b, _ := json.Marshal(st)
	return string(b)
}

// decodeState accepts the JSON form and the bare float that fields written
// before the rate term hold, so a rolling deploy reads the old pods' scores
// as {score: v}.
func decodeState(val string) (State, error) {
	if len(val) > 0 && val[0] == '{' {
		var st State
		if err := json.Unmarshal([]byte(val), &st); err != nil {
			return State{}, fmt.Errorf("parse state: %w", err)
		}
		return st, nil
	}
	f, err := strconv.ParseFloat(val, 64)
	if err != nil {
		return State{}, fmt.Errorf("parse legacy score: %w", err)
	}
	return State{Score: f}, nil
}

// relay/scoresink.go
package relay

import (
	"sync"

	"github.com/pokt-network/sage/domain"
	"github.com/pokt-network/sage/reputation"
)

// ScoreSink collapses the per-attempt signals of one batch request to one
// signal per (endpoint, RPC type): the worst severity seen, carrying that
// signal's reason and the maximum latency observed for the endpoint.
//
// It is shared across the whole request tree on purpose — batch puts one on
// the parent context before cloning, and Clone() is shallow, so every
// sub-relay (and every retry and hedge arm inside those) adds to the same
// sink. That sharing is the mechanism, not an accident; the mutex is what
// makes it safe.
type ScoreSink struct {
	mu    sync.Mutex
	worst map[sinkKey]reputation.Signal
}

type sinkKey struct {
	ep  domain.EndpointAddr
	rpc domain.RPCType
}

// NewScoreSink returns an empty sink.
func NewScoreSink() *ScoreSink {
	return &ScoreSink{worst: make(map[sinkKey]reputation.Signal)}
}

// severityRank orders signal types for worst-of. Higher is worse.
func severityRank(t reputation.SignalType) int {
	switch t {
	case reputation.SignalFatalError:
		return 4
	case reputation.SignalCriticalError:
		return 3
	case reputation.SignalMajorError:
		return 2
	case reputation.SignalMinorError:
		return 1
	default:
		return 0
	}
}

// Add records one attempt's signal for an endpoint.
func (s *ScoreSink) Add(ep domain.EndpointAddr, rpc domain.RPCType, sig reputation.Signal) {
	k := sinkKey{ep, rpc}
	s.mu.Lock()
	defer s.mu.Unlock()
	cur, ok := s.worst[k]
	if !ok {
		s.worst[k] = sig
		return
	}
	if severityRank(sig.Type) > severityRank(cur.Type) {
		latency := cur.Latency
		if sig.Latency > latency {
			latency = sig.Latency
		}
		sig.Latency = latency
		s.worst[k] = sig
		return
	}
	if sig.Latency > cur.Latency {
		cur.Latency = sig.Latency
		s.worst[k] = cur
	}
}

// Flush calls fn once per (endpoint, RPC type) with the collapsed signal and
// empties the sink.
func (s *ScoreSink) Flush(fn func(ep domain.EndpointAddr, rpc domain.RPCType, sig reputation.Signal)) {
	s.mu.Lock()
	worst := s.worst
	s.worst = make(map[sinkKey]reputation.Signal)
	s.mu.Unlock()
	for k, sig := range worst {
		fn(k.ep, k.rpc, sig)
	}
}

package middleware

import (
	"context"
	"time"

	"github.com/pokt-network/sage/featureflag"
	"github.com/pokt-network/sage/relay"
	"github.com/pokt-network/sage/reputation"
)

// Score records one reputation signal per relay attempt, for the endpoint
// that served it, from the verdict that attempt produced. It sits inside
// retry, hedge and batch and directly outside heuristic, so a retried or
// hedged attempt that lost is still scored, and a batch item is scored once
// per endpoint through the sink batch installs (docs/scoring.md §4.1–4.3).
//
// Grading is buildSignal — the same table Observe used when it scored per
// client request. A client-attributed error (a hang-up, a method the chain
// does not have) is nobody's signal and is dropped here, so it is not an
// attempt for the rate term either.
//
// Gated by scoring_v2. Off, this is a pass-through and Observe scores as
// before; on, Observe records nothing.
func Score(flags featureflag.FlagStore, repSvc reputation.Service) relay.Middleware {
	return func(next relay.Handler) relay.Handler {
		return relay.HandlerFunc(func(ctx *relay.Context) error {
			if repSvc == nil || (flags != nil && !flags.IsEnabled(ctx.Ctx, featureflag.FlagScoringV2, ctx.ServiceID)) {
				return next.HandleRelay(ctx)
			}
			start := time.Now()
			err := next.HandleRelay(ctx)
			if ctx.Endpoint == "" {
				return err
			}
			sig := buildSignal(ctx, err, time.Since(start))
			if sig.Type == "" {
				return err
			}
			if ctx.ScoreSink != nil {
				ctx.ScoreSink.Add(ctx.Endpoint, ctx.RPCType, sig)
				return err
			}
			// Best-effort, as Observe was: never block a relay on scoring.
			_ = repSvc.RecordSignal(context.Background(), ctx.ServiceID, ctx.Endpoint, ctx.RPCType, sig)
			return err
		})
	}
}
