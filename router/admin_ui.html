Reputation scores

Keys are reputation keys at the configured granularity — per backend URL by default — not endpoint addresses. Several staked suppliers routinely front one URL and share its score. Worst first. Score is what the selector uses: the additive term plus the chronic-failure penalty. "Probe only" marks a key nothing but health checks has graded, so its score is evidence about the probe payload, not about client traffic.

Operator drains

A drain benches every endpoint whose URL resolves to the given registrable domain, for one RPC type or all of them, until it expires. Draining the last operator standing for a service is refused (409): selection would have nothing left to pick from.

Blocked domains

      

        A blocked domain is excluded from selection on every service, for every RPC
        type or only the listed ones, permanently until released. Unlike a drain it
        has no expiry and no service. Config entries come from the file (and
        SAGE_BLOCKED_DOMAINS) and are changed by editing it and reloading;
        admin entries are set here and, with Redis, reach every replica and survive a
        restart.

        Domains currently broken for a service. Breaks expire lazily, so one listed
        with a past expiry is not actually locked out. Clearing releases the break;
        escalation history deliberately survives, so a domain let back in and failing
        again is still a repeat offender.
